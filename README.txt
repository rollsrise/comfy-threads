COMFY THREADS WEBSITE — CATEGORY PAGES VERSION

Files: index.html, style.css, script.js, plus individual category/subcategory HTML pages.

SLIDER: The hero slider no longer auto-advances. Use the arrows or dots to change slides manually.

CATEGORY PAGES: Navigation dropdowns and category strip link to separate pages. Each category/subcategory page has four stock-photo placeholders and an enquiry link to the quote form on index.html.

IMPORTANT: Stock images are loaded from Unsplash URLs and need an internet connection. Product cards are layout placeholders, not confirmed live products. The quote form uses the existing email-app fallback; connect a form service to receive submissions directly.

To preview, open index.html in a browser. Keep all HTML files, style.css and script.js together in the same folder when uploading to hosting.
